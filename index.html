MULAI DI IPHONE

Jalankan GlassScan

  1. Unggah folder ini ke repositori GitHub milikmu.
  2. Aktifkan GitHub Pages untuk repositori tersebut.
  3. Buka alamat HTTPS-nya di Safari dan pilih Bagikan → Tambahkan ke Layar Utama.
  4. Buka sekali saat online agar aset tersimpan; setelah itu coba mode pesawat.

Catatan: ini prototipe web/PWA, bukan aplikasi iOS native. Kamera dan pemasangan offline memerlukan halaman HTTPS; membuka index.html langsung dari Files tidak cukup.
